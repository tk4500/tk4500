Desenvolvedor **FullStack** formado em Análise e Desenvolvimento de Sistemas (IFSC), com raízes em Mecatrônica e Robótica. Apaixonado por construir soluções completas — do banco de dados ao pixel na tela.

### 🚀 Sobre Mim

Comecei na tecnologia pela Mecatrônica e Automação, o que me deu uma base sólida em lógica e integração de sistemas. Hoje atuo em desenvolvimento **Full Cycle**: microsserviços (Java/Spring Boot), interfaces modernas (Angular, Vue 3, React), backends em Python (FastAPI) e esteiras CI/CD em Cloud.

Tenho experiência real com integrações B2B, deploy em VPS/Oracle Cloud, automação com IA (Gemini, Ollama) e publicação de extensões na Chrome Web Store. Gosto de projetos que entregam valor concreto para quem usa.
