### 🚀 Sobre Mim

Minha jornada na tecnologia começou com uma formação técnica em Mecatrônica, Robótica e Automação, onde desenvolvi uma base sólida em lógica e uma paixão pela integração de sistemas. Recentemente, concluí meu curso superior de Análise e Desenvolvimento de Sistemas no IFSC, consolidando minha transição para o desenvolvimento de software.

Tenho experiência prática no desenvolvimento de aplicações **Full Cycle**, atuando desde a construção de microsserviços (Java/Spring) e interfaces dinâmicas (Angular/React), até a arquitetura de backend com Python (FastAPI) e a implementação de esteiras de deploy (CI/CD) em infraestrutura Cloud. Amo o processo de transformar ideias em realidade através do código e estou sempre em busca de novos desafios para entregar valor real aos usuários.

### 🌱 Projetos e Foco Atual

Abaixo estão alguns destaques de projetos recentes, acadêmicos e pessoais, onde aplico e expando meus conhecimentos:

* **⚙️ [Integração B2B com ERP WinThor](https://github.com/tk4500/docker-pdf-winthor)**
    * **Descrição:** Aplicação Full Cycle desenvolvida para automação de processos B2B. O sistema realiza o processamento em lote de pedidos gerados por PDFs e a integração/sincronização de dados via APIs REST com o ERP WinThor (TOTVS).
    * **Tecnologias:** Python (FastAPI), React, Docker, Oracle Cloud, Caddy, CI/CD com GitHub Actions e PostgreSQL seguro via túnel SSH.
* **🤖 [Automação de Candidaturas com IA](https://github.com/tk4500/resume-ai-extension)**
    * **Descrição:** Desenvolvendo um bot para automação de triagem e candidaturas em vagas de emprego, integrando scripts de automação com a API do Gemini para analisar o *fit* da vaga com o meu perfil e localização.
* **🎮 [Dev's Journey](https://github.com/tk4500/devsjourney-97162)**
    * **Descrição:** Projeto que fez parte do meu TCC. É uma plataforma web para um jogo que ensina programação utilizando blocos, ilustrando de forma lúdica a rotina de um desenvolvedor.
    * **Tecnologias:** Angular e TypeScript no front-end, focando em componentização avançada e interatividade.
